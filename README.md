# groove-attention-economics
 independent research study examining the relationship between groove-oriented short-form video content, user engagement behavior, and recommendation-driven consumption.
 # Attention Economics in the Age of Artificial Intelligence
### The Impact of Algorithmic Groove Music Recommendations on Social Media Users

DOI- https://doi.org/10.5281/zenodo.22676639

## 📌 Project Overview
This repository contains the computational pipeline and data analysis for an independent research project examining how groove-edited short-form music videos interact with recommender systems to drive repetitive digital consumption.

## 🔬 Core Insights & Modeling (Computational Method)
We formalized user engagement signals into a predictive framework using Logistic Regression with 5-fold Stratified Cross-Validation:
* **Behavior-only Model (Base):** (Replay urge + listening frequency + recommendations) -> Achieved **CV ROC-AUC: 0.8429**
* **Extended Predictive Model:** (Adding algorithm-influence perception) -> Achieved **CV ROC-AUC: 0.8912**

## 📊 Experimental Results (N=20 Pilot)
Controlled music contrast experiment (Condition Y vs Control X) demonstrated statistically supported directional differences (Holm-adjusted):
* **Mean Enjoyment:** +2.20 increase
* **Mean Motivation:** +2.40 increase
* **Similar-Video Intention:** +1.70 increase

## ⚠️ Important Scientific Boundaries & Limitations
* **Observational Only:** Survey findings indicate strong behavioral associations, not platform-level causal effects.
* **No Direct Biological Measure:** Dopamine and neurochemical reward circuits are discussed as conceptual literature context only; no neuroimaging or biomarkers were directly tracked in this study.
